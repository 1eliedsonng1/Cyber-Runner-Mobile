# Cyber-Runner-Mobile
🎮 Cyber Runner Mobile

Cyber Runner Mobile é um jogo desenvolvido inteiramente em HTML5, com CSS3 e JavaScript integrados em um único arquivo, criado para rodar diretamente no navegador, sem necessidade de instalação.

O jogo é leve, rápido e responsivo, oferecendo uma experiência fluida tanto em dispositivos móveis quanto em computadores, com foco em jogabilidade simples e desempenho otimizado.


---

🚀 Características

🎯 Jogo em arquivo único (index.html)

📱 Totalmente compatível com celulares (mobile)

💻 Funciona em navegadores modernos

⚡ Carregamento rápido e baixo consumo de dados

🧩 Código organizado e fácil de editar



---

🛠️ Tecnologias Utilizadas

HTML5

CSS3

JavaScript (Vanilla)



---

🌐 Jogue Online

O jogo pode ser acessado diretamente pelo navegador através do GitHub Pages após a ativação do repositório.
